# Vavo Academy

Gotowy, statyczny landing page pod GitHub i Vercel.

## Publikacja

Wrzuć wszystkie pliki z paczki bezpośrednio do głównego katalogu repozytorium. Vercel wykryje `index.html` automatycznie. Domena docelowa: `vavoacademy.pl`.

## Przed reklamą

1. W Stripe wykonaj testową płatność 50 zł i sprawdź wiadomość potwierdzającą.
2. Upewnij się, że limit Payment Link nadal wynosi 50 skutecznych płatności.
3. Po podpięciu domeny dodaj `https://vavoacademy.pl/sitemap.xml` w Google Search Console.
